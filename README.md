# 🧑‍🏫( The Tutor  ) - المنصة التعليمية الذكية

**The Tutor (ذا تيوتور)** هي منصة تعليمية إلكترونية متكاملة (SaaS) مصممة خصيصًا لدعم طلاب المرحلة الابتدائية (من الصف الأول إلى السادس الابتدائي) في المنهج المصري للتعليم التجريبي ومدارس اللغات. تهدف المنصة إلى تحويل عملية التعلم إلى تجربة تفاعلية ممتعة وشاملة، من خلال دمج الألعاب التفاعلية، شروحات الفيديو، متابعة أولياء الأمور، وتكامل معايير تتبع التعلم المتقدمة.

---

## 🎯 الرؤية
تقديم بيئة تعليمية تفاعلية آمنة وجذابة للطفل تعتمد على تصميم بصري حيوي وحديث بألوان هادئة وخلفيات جرافيك تفاعلية، وتوفر لكل من الطالب وولي الأمر والسوبر أدمن الأدوات اللازمة لمتابعة وإدارة العملية التعليمية بكفاءة عالية وبدون تعقيد.

### 🎮 نظام الألعاب والأسئلة التفاعلية
-الألعاب تنقسم الي اربع مستويات داخل كل سنة دراسية 
لعبة اختبار في الترم علي المادة شاملة و الأسئلة تاتي علي الدروس التي تم مذكرتها في الجدول الزمني للدراسة 
و لعبة علي وحدة و لعبة علي كل درس

 **اللعبة**: اختار واختبر نفسك في كل المواد مع **9 أسئلة كحد أدنى**، مع وجود زر إضافة أسئلة (`+ Add Questions`) لزيادة العدد حسب رغبة المستخدم.
- **لعبة تقييم الدرس**: لعبة تفاعلية ملونة مخصصة داخل كل درس تضمن قياس فهم الطفل لمحتوى هذا الدرس تحديداً في أي وقت، مع إمكانية التوسع في عدد الأسئلة.

---

### 📊 التتبع المتقدم والتقارير (LRS Integration)
- **تفعيل بروتوكول xAPI (Learning Record Store - LRS)**: تسجيل وتتبع كافة تفاعلات الطالب (مشاهدة الشرح، حل الألعاب، نتائج الاختبارات) بصيغة `(Actor - Verb - Object)`.
- **خصوصية البيانات (RLS)**: تطبيق سياسات الأمان العالية في قاعدة البيانات لضمان عدم اطلاع أي مستخدم إلا على البيانات والتقارير الخاصة به فقط.

## 👥 فئات المستخدمين ولواحق التحكم

1. **السوبر أدمن (Super Admin)**:
   - إنشاء الحسابات وتوليد (Username / Password).
  - انشاء رمز عوة لولي الأمر لمتابعة طالب
 - إدارة روابط فيديوهات الشرح على يوتيوب وتحديث الرابط المعطوب فوراً.
- إدارة روابط الألعاب وتحديثها   
- إدارة الاشتراكات (شهري / سنوي) وتفعيل الحركة العامة للمنصة.
2. **ولي الأمر (Parent)**:
   - الدخول من خلال رمز دعوة يحصل علية من السوبر ادمن لمتابعة التقدم الدراسي، درجات الألعاب، وتقارير أداء الأبناء.  
3. **الطالب (Student)**:
   - استعراض المنهج حسب الصف الدراسي، مشاهدة فيديوهات الشرح، خوض الألعاب، ورفع الواجبات.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend)**: React 18, TypeScript, Tailwind CSS, Lucide-React.
- **الباك إند (Backend)**: Python, FastAPI, Uvicorn.
- **قاعدة البيانات والمصادقة**: Supabase (PostgreSQL, Supabase Auth).
- **إدارة الملفات والواجبات**: Google Drive & Google Sheets API.
- **تتبع التعلم**: xAPI / LRS (Learning Record Store Standard).
- **بيئة البناء والتجميع**: Vite / Esbuild (متوافقة بالكامل مع بيئات Linux/ARM64).

---

## ⚙️ آلية العمل الأساسية

1. يتسلم ولي الأمر والطالب اسم المستخدم وكلمة المرور المُنشأة من قبل السوبر أدمن.
2. عند تسجل الدخول عبر **Supabase Auth** يتم توجيه المستخدم لوجهته المحددة حسب صلاحياته (صف دراسي / لوحة تحكم).
3. يختار الطالب المادة والدرس، يشاهد شرح الفيديو المربوط بـ YouTube، ويخوض لعبة الدرس التفاعلية.
4. تُرسل بيانات التفاعل تلقائياً إلى قاعدة البيانات وسجل الـ **LRS**.
5. يرفع الطالب واجباته في صفحة المذاكرة الخاصة لتُحفظ على **Google Drive**.
6. يتابع ولي الأمر والسوبر أدمن التقارير اليومية والشهرية فورياً عبر لوحات التحكم.
